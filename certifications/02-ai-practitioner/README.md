# AWS Certified AI Practitioner (AIF-C01)

> **Status:** 🔜 Planejada · **Nível:** Foundational · **Página oficial:** <https://aws.amazon.com/certification/certified-ai-practitioner/>

## Por que está na trilha

Fundamentos de IA, ML e IA Generativa na AWS: conceitos, serviços (SageMaker, Bedrock, serviços de IA prontos) e IA responsável. É a base conceitual de tudo que vem depois na trilha.

## Antes de começar

- [ ] Ler o exam guide oficial e registrar aqui os domínios e pesos
- [ ] Escolher curso (o Stephane Maarek tem um para a AIF-C01) e simulados
- [ ] Criar `notes/`, `labs/` e `practice-exams/` no modelo da [CLF-C02](../01-cloud-practitioner/)
- [ ] Usar o voucher de 50% da CLF-C02 para agendar

## Observações

- A seção **15 (Machine Learning)** da CLF-C02 é uma prévia direta desta prova.
- Primeira certificação onde vale começar labs com Python + `boto3` (ex.: chamar um modelo no Bedrock).
