## Resumo (com as minhas palavras)

A AWS (Amazon Web Services) é a plataforma de nuvem da Amazon, com serviços de computação, armazenamento, redes, segurança e bancos de dados, entre outros.

## Serviços e conceitos

| Serviço / conceito | O que é | Quando usar |
|---|---|---|
| AWS (Amazon Web Services) | Plataforma de nuvem da Amazon | Hospedar sites e APIs, armazenar arquivos, executar aplicações e bancos de dados |

## Pegadinhas de prova

- Seção de apresentação do curso: não traz conteúdo cobrado na prova.

## Conexão com dados / ML

- Como a AWS oferece bancos de dados, armazenamento e poder de processamento, também dá para construir aplicações de ML e IA dentro dela.
