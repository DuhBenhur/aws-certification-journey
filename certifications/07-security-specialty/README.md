# AWS Certified Security – Specialty (SCS-C03)

> **Status:** 🔜 Planejada · **Nível:** Specialty · **Página oficial:** <https://aws.amazon.com/certification/certified-security-specialty/>

## Por que está na trilha

Segurança em profundidade: identidade, criptografia, detecção, resposta a incidentes e proteção de dados. Para quem trabalha com dados e IA, proteger datasets, modelos e aplicações é um diferencial sênior.

## Antes de começar

- [ ] Ler o exam guide oficial e registrar aqui os domínios e pesos
- [ ] Escolher curso e simulados
- [ ] Criar `notes/`, `labs/` e `practice-exams/` no modelo da [CLF-C02](../01-cloud-practitioner/)

## Observações

- A SCS-C03 está vigente desde dezembro de 2025 e substituiu a SCS-C02. Cuidado com materiais antigos.
