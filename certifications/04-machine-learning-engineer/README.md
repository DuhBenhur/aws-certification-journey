# AWS Certified Machine Learning Engineer – Associate (MLA-C01)

> **Status:** 🔜 Planejada · **Nível:** Associate · **Página oficial:** <https://aws.amazon.com/certification/certified-machine-learning-engineer-associate/>

## Por que está na trilha

O núcleo técnico da trilha: preparação de dados, treino, deploy e operação de modelos com SageMaker e o ecossistema de dados da AWS (S3, Glue, Athena, Kinesis). É onde a virada para Engenharia de ML se materializa.

## Antes de começar

- [ ] Ler o exam guide oficial e registrar aqui os domínios e pesos
- [ ] Escolher curso e simulados
- [ ] Criar `notes/`, `labs/` e `practice-exams/` no modelo da [CLF-C02](../01-cloud-practitioner/)
- [ ] Adicionar `scikit-learn` e o SDK do SageMaker ao `requirements.txt`

## Observações

- **Python vira obrigatório aqui.** A trilha em [python/](../../python/) deve estar nas fases 3–4 antes de começar.
- Labs desta prova são os mais valiosos para o portfólio: pipeline de dados + treino + endpoint, com custo controlado.
